# programming.borck.education

Single-page hub for Michael Borck's programming education properties:

- **Speak Software** — twelve hands-on labs on building software through natural-language collaboration with AI agents ([programminglabs.borck.education](https://programminglabs.borck.education))
- **HandsOnAI** — pip-installable toolkit for teaching how modern AI systems work ([handsonai.borck.education](https://handsonai.borck.education))
- **One Calculator, Three Paradigms** — the same calculator in imperative, functional, and OO Python, runnable in the browser ([programmingparadigms.borck.education](https://programmingparadigms.borck.education))
- **The Calculator Walkthrough** — a notebook kata taking one calculator from first design to best practice ([calculatorwalkthrough.borck.education](https://calculatorwalkthrough.borck.education))
- **Objectville** — object-oriented Python through a subway system ([objectville.borck.education](https://objectville.borck.education))
- **Programming Toys** — single-file interactive pages that each break one programming misconception ([programmingtoys.borck.education](https://programmingtoys.borck.education))
- Published packages on PyPI and npm

Plain HTML/CSS, served via GitHub Pages. Sister site to [borck.education](https://borck.education);
the companion books on intentional AI collaboration live at
[books.borck.education](https://books.borck.education), and the toys' AI and security siblings at
[aitoys.borck.education](https://aitoys.borck.education) and
[securitytoys.borck.education](https://securitytoys.borck.education).
